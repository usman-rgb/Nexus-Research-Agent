# Nexus-Research-Agent
Nexus Research Agent is an autonomous AI assistant powered by LangGraph and FastAPI. It uses a ReAct workflow to intelligently search ArXiv and the web, streaming its real-time reasoning and fully cited Markdown reports to a modern, 3D neumorphic web interface.  Tech Stack: FastAPI, LangGraph (ReAct), OpenAI/Gemini, HTML/CSS/JS.
